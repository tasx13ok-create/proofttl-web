ProofTTL / independent verification

Verify a signed Fact Lease.

This page performs Ed25519 verification locally in your browser. It verifies both the immutable issuance signature and, when present, the signed SHA-256-linked monitoring event chain.

Current settlement network: Base Sepolia testnet. Verification of signatures is real cryptography; payment settlement is not mainnet.
Lease summary
Signed verification history

New monitoring events can carry their own Ed25519 signature and a hash pointer to the previous event. That makes deletion, reordering, or modification detectable by this verifier.

Verification method

Issuance signs canonical issued_attestation. Event-chain v1 signs canonical event_attestation objects containing the Lease ID, event index, previous-event hash, and event payload. All checks use the published ProofTTL Ed25519 key.
