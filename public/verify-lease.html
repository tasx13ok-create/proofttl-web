Verify a signed Fact Lease.

This page performs Ed25519 verification in your browser using WebCrypto. The signature check is local. You can fetch a Lease by ID or paste a Lease JSON object directly.

Current settlement network: Base Sepolia testnet. Verification of signatures is real cryptography; payment settlement is not mainnet.

Append-only verification history

These events are returned inside the Lease object. The issuance signature covers the immutable issuance attestation; monitoring fields and later events remain mutable state and are shown separately.

Verification method

ProofTTL signs the canonical JSON form of issued_attestation with Ed25519. This verifier rebuilds the expected issuance attestation from the Lease, compares it to the stored attestation, fetches the matching published public key from the ProofTTL key-discovery endpoint, and verifies the signature locally.
